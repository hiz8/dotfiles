# Commit

## 概要

ローカルの変更を、表示幅ルールを含むコミットメッセージ規約に従ってコミットします。

このスキルはコミット作業一式を **subagent にディスパッチ** し、メインのコンテキストには
結果のサマリだけを残します。判断と実行はすべて subagent の側で完結させます。

## 手順

1. 自分で git の調査・ステージ・コミットをしてはいけません。このスキルを読み込んだときに
   示される `Base directory for this skill:` の絶対パスを `[SKILL_DIR]` として、`Agent`
   ツールで `general-purpose` の subagent を 1 つディスパッチしてください。

2. subagent へのプロンプトには次を含めてください。

   - `[SKILL_DIR]` の実際の値（絶対パス）
   - `[SKILL_DIR]/references/commit-procedure.md` を読み、その手順に厳密に従ってローカルの
     変更をコミットすること
   - ユーザーがコミット対象・粒度・メッセージについて指示を出していれば、その内容を
     そのまま伝えること（例: 「認証まわりの変更だけコミット」「2コミットに分けて」）
   - 戻り値は簡潔なサマリだけにすること。手順書の「呼び出し元へ返すサマリ」に従わせます

3. subagent が返したサマリをユーザーに提示してください。エラーや「コミット対象なし」が
   返った場合も、その内容をそのまま伝えてください。

## 危険信号

次のように考えたら、**止まってください**。自分で作業せず、subagent にディスパッチします。

- 「自分で git を叩いたほうが早い」
- 「diff を読み込んで内容を確認しておこう」
- 「規約を読んでメッセージを自分で組み立てよう」
