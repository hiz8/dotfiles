# commit スキルの拡張の置き場所を git config で指定する 設計（短）

## 意図

- 拡張の置き場所が `.claude/commit/` に固定されていると、Claude 向けの名前に縛られる。
  u-motion-front では devin-cli も併用するため、ツール名に依存しない形にしたい（ユーザー）。
- 置き場所はユーザーが選べるようにしたい（例: 既存の `.claude/docs/` の下）。

## 検討した方式

- A. git config で拡張ディレクトリを指定する。**ユーザーが選択。**
- B. ツール名を含まない固定ディレクトリ（例 `.commit/`）。名前の決め打ちが残るため不採用。
- C. 今の `.claude/commit/` のまま。ツール名に縛られるため不採用。

## 決まった設計

- キー `commit-skill.extensionDir` に拡張ディレクトリのパスを書く。推奨は `--local`
  （メインと全 worktree で共有され、git 管理外）。
- 相対パスはメインの作業ツリーのルートから解決する（git 管理外のファイルは linked worktree に
  入らないため）。`~` は git の `--type=path` で展開する。
- 設定がない、または git の外 → 共通規約。`.claude/commit/` などを暗黙に探すことはしない
  （ユーザーが決定。探す場所が 2 つあるとどちらが使われたか分かりにくくなるため）。
- 設定があるのに指すディレクトリがない・ディレクトリでない・中身が壊れている → 今と同じく
  ExtensionError で止める（終了コード 2）。
- ディレクトリの中身（`config.json` と接頭辞ガイド）と `--show-rules` の出力は今のまま。
- 「今いる作業ツリー → メインの作業ツリー」の順に探す処理は廃止する。

## 移行

- u-motion-front のメインの作業ツリーで、ユーザーが選んだ場所に 2 ファイルを置き、
  `git config --local commit-skill.extensionDir <パス>` を設定する。
