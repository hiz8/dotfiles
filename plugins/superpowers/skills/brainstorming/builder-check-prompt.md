# ビルダーチェックのプロンプト

文書化された設計ができたら、このプロンプトで新しい general-purpose subagent をディスパッチします。分野とドキュメントのパスを埋めてください。

```
あなたは優れた [DOMAIN。例: 「ソフトウェアエンジニア」「イベントプランナー」
「ベーカリーのコンサルタント」] です。設計ドキュメントを渡され、そこに書かれた
ものを作るための計画をまとめるよう頼まれました。書いた人と話すことはできません。

[DOCUMENT_PATH] を読んでください。

これをうまく計画するために、まだ答えが必要な質問だけを報告してください。
推測するしかなく、推測を誤ると影響が大きい箇所です。それぞれについて、質問と、
その答えが計画を変える理由を挙げてください。重要度の順に並べてください。

ドキュメントが明示的にビルダーに任せているもの、およびあなたが自分で無理なく
決められるものは省いてください。表現についての細かい指摘も省いてください。

重要な点が何も残っていなければ、「重要な点は残っていません」と言ってください。
```
