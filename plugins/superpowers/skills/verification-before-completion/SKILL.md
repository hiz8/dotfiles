# Verification Before Completion

## 概要

**基本原則:** 主張より先に、常に証拠を示してください。

**このルールの文言に違反することは、このルールの精神に違反することです。**

## 鉄則

```
新しい検証の証拠がない限り、完了を主張してはいけません
```

このメッセージ内で検証コマンドを実行していなければ、通ったと主張してはいけません。

## ゲート関数

```
何らかの状態を主張する前、または満足を表明する前に:

1. 特定: どのコマンドがこの主張を証明するか？
2. 実行: コマンドの全体を実行する（新しく、完全に）
3. 読む: 出力の全体を読み、終了コードを確認し、失敗を数える
4. 検証: 出力は主張を裏付けているか？
   - いいえ: 実際の状態を、証拠とともに述べる
   - はい: 主張を、証拠とともに述べる
5. そこで初めて: 主張する

どの手順を飛ばしても、それは検証ではなく嘘です
```

## よくある失敗

| 主張 | 必要なもの | 不十分なもの |
|------|-----------|--------------|
| テストが通る | テストコマンドの出力: 失敗 0 件 | 以前の実行、「通るはず」 |
| リンターがクリーン | リンターの出力: エラー 0 件 | 部分的なチェック、推測による外挿 |
| ビルドが成功する | ビルドコマンド: 終了コード 0 | リンターが通ったこと、ログが良さそうに見えること |
| バグが直った | 元の症状をテストする: 通る | コードを変更した、直ったと思い込んでいる |
| リグレッションテストが機能する | Red-Green のサイクルを確認済み | テストが 1 回通った |
| エージェントが完了した | VCS の diff が変更を示している | エージェントが「成功」と報告した |
| 要件を満たしている | 1 行ずつのチェックリスト | テストが通っている |

## 危険信号 - 止まってください

- 「はず」「おそらく」「〜のようだ」を使っている
- 検証の前に満足を表している（「よし！」「完璧！」「完了！」など）
- 検証せずにコミット/プッシュ/PR をしようとしている
- エージェントの成功報告を信用している
- 部分的な検証に頼っている
- 「今回だけ」と考えている
- 疲れていて、作業を終わらせたい
- **検証を実行せずに成功を匂わせる、あらゆる言い回し**

## 自己正当化の防止

| 言い訳 | 現実 |
|--------|------|
| 「もう動くはず」 | 検証を**実行**してください |
| 「自信がある」 | 自信 ≠ 証拠 |
| 「今回だけ」 | 例外はありません |
| 「リンターは通った」 | リンター ≠ コンパイラ |
| 「エージェントが成功と言った」 | 独立して検証してください |
| 「疲れている」 | 疲労 ≠ 言い訳 |
| 「部分的なチェックで十分」 | 部分的なものは何も証明しません |
| 「言葉が違うからルールは当てはまらない」 | 文言より精神 |

## 主なパターン

**テスト:**
```
✅ [テストコマンドを実行] [確認: 34/34 通過] 「全テスト通過」
❌ 「もう通るはず」 / 「正しそうに見える」
```

**リグレッションテスト（TDD の Red-Green）:**
```
✅ 書く → 実行（通る） → 修正を戻す → 実行（必ず失敗しなければならない） → 修正を復元 → 実行（通る）
❌ 「リグレッションテストを書いた」（red-green の検証なし）
```

**ビルド:**
```
✅ [ビルドを実行] [確認: 終了コード 0] 「ビルド成功」
❌ 「リンターは通った」（リンターはコンパイルを確認しない）
```

**要件:**
```
✅ 計画書を読み直す → チェックリストを作る → 各項目を検証する → 不足または完了を報告する
❌ 「テストが通ったので、フェーズ完了」
```

**エージェントへの委任:**
```
✅ エージェントが成功を報告 → VCS の diff を確認 → 変更を検証 → 実際の状態を報告
❌ エージェントの報告を信用する
```

## 適用するとき

**次の前には常に:**
- 成功・完了を主張する、あらゆる言い方
- 満足を表す、あらゆる表現
- 作業の状態について肯定的に述べる、あらゆる発言
- コミット、PR 作成、タスクの完了
- 次のタスクへの移行
- エージェントへの委任

**このルールが適用されるもの:**
- 正確な言い回し
- 言い換えと類義語
- 成功を示唆する含み
- 完了/正しさをうかがわせる、あらゆるコミュニケーション
