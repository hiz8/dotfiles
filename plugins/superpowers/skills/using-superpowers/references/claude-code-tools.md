# Claude Code ツールに関する注記

Claude Code は基準となるハーネスです。スキルは Claude Code の用語（subagent のディスパッチには `Agent`、todo、`Skill`）で書かれています。この注記は、Claude Code がスキルのデフォルトの形より安く計画を実行できる唯一の場面を扱います。これは人間のパートナーが選んだときだけ使う（opt-in）もので、スキルが要求することは何も変えません。

## subagent-driven-development のオーケストレーションを安くする

superpowers:subagent-driven-development の実行で、コントローラーのセッションは最も高くつく席です。すべてのディスパッチ結果とすべてのレポートを読み、通常はそのセッションで最も高性能なモデルで動きます。Claude Code はネストした subagent をサポートしている（デフォルトではメインの会話から 3 階層下まで。`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` で調整できます）ので、ループ全体を 1 階層下で実行できます。

人間のパートナーがそれを求めたとき — あるいは、セッションのモデルは調整作業に使うには高すぎると言ったとき — 中位のモデルで**1 つだけ**オーケストレーター subagent をディスパッチし、計画書のパスと、superpowers:subagent-driven-development を最初から最後まで使うようにという指示を渡してください。オーケストレーターは、そのスキルの「モデル選択」に従って自分で実装者とレビュアーをディスパッチします。ワークスペースと ledger はディスク上にあるので、階層が 1 つ増えても何も失われません。オーケストレーターの最終メッセージには「自分が下した裁定」リストを一字一句そのまま含めなければなりません — そのリストが判断を人間のパートナーに届ける手段であり、あなたはそれを要約せず、そのまま中継してください。

これは計画全体に対してだけ行ってください。単一タスクのディスパッチをネストしても得るものはなく、席が 1 つ増えるだけです。
